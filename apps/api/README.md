# API

Backend do MOVA organizado como monólito modular. Os módulos de negócio serão definidos a partir das regras de domínio, sem antecipar uma divisão que ainda não foi validada.

## Integração

OpenAPI é o contrato explícito de comunicação com a aplicação web. A API não importa código-fonte da web nem de outros aplicativos. Cada aplicação mantém dependências, build, testes e deploy independentes.

## Estado

Framework, runtime, versão e destino de deploy ainda não foram escolhidos. A especificação OpenAPI executável será criada junto aos endpoints e critérios de validação aprovados.
